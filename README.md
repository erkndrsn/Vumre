# Vera Muhabbet Umre Organizasyon Uygulaması

Türkçe umre organizasyon paneli; yolcu kayıtlarını, kafileleri, hazırlık görevlerini ve ödeme durumlarını takip eder.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda açın veya depo dizininde yerel bir web sunucusu başlatın:

```sh
python3 -m http.server 8000
```

Ardından `http://localhost:8000` adresini ziyaret edin.

Uygulama örnek verilerle gelir. Eklediğiniz yolcu kayıtları sunucuya gönderilmez; yalnızca aynı tarayıcının yerel depolamasında saklanır.
